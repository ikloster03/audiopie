## Why

AudioPie currently only understands a single kind of project: one audiobook, saved as one `.audiopie` file. Users who work on multi-book series have no way to represent the series itself (its shared identity, ordering, and shared metadata like author/narrator/cover) or to quickly start a new book that reuses the previous book's settings. This addresses GitHub issues [#28](https://github.com/ikloster03/audiopie/issues/28) (project types: Audiobook vs. Series) and [#27](https://github.com/ikloster03/audiopie/issues/27) (create a new project from an existing one).

**RU:** Сейчас AudioPie понимает только один тип проекта — одна аудиокнига, сохранённая в одном `.audiopie`-файле. У пользователей, работающих над сериями из нескольких книг, нет способа представить саму серию (её идентичность, порядок книг, общие метаданные вроде автора/чтеца/обложки) или быстро начать новую книгу на основе настроек предыдущей. Это закрывает issues #28 (типы проектов: аудиокнига/серия) и #27 (создание нового проекта на основе существующего).

## What Changes

- Introduce a `type` field on projects: `audiobook` (existing behavior, default) or `series`.
  - **RU:** Ввести поле `type` у проектов: `audiobook` (существующее поведение, по умолчанию) или `series`.
- A `series` project is a lightweight project that holds series-level metadata (title, author, narrator, cover, description) plus an ordered list of references (file paths) to `audiobook` project files that belong to it. It does NOT itself contain tracks/chapters.
  - **RU:** Проект `series` — это лёгкий проект, хранящий метаданные уровня серии (название, автор, чтец, обложка, описание) и упорядоченный список ссылок (путей к файлам) на входящие в неё проекты `audiobook`. Сам он НЕ содержит треков/глав.
- Existing `.audiopie` files without a `type` field SHALL be treated as `type: 'audiobook'` for backward compatibility. **Not breaking** for existing saved projects.
  - **RU:** Существующие `.audiopie`-файлы без поля `type` ДОЛЖНЫ считаться `type: 'audiobook'` для обратной совместимости. Не является ломающим изменением для уже сохранённых проектов.
- The Project Manager screen (`ProjectManager.tsx`) gains a choice of project type when creating new: "New Audiobook" or "New Series".
  - **RU:** Экран менеджера проектов (`ProjectManager.tsx`) получает выбор типа проекта при создании нового: «Новая аудиокнига» или «Новая серия».
- A `series` project's editing view lets the user add/remove/reorder audiobook references and open a referenced audiobook project directly.
  - **RU:** Экран редактирования проекта `series` позволяет пользователю добавлять/удалять/переупорядочивать ссылки на аудиокниги и открывать связанный проект аудиокниги напрямую.
- Add "Create new project from existing project": when creating a new `audiobook` project, the user may optionally pick an existing `.audiopie` file as a template; the new project is pre-filled with that project's metadata (author, narrator, genre, publisher, series, cover) but starts with empty tracks/chapters and no remembered file path (so it must be saved separately).
  - **RU:** Добавить «Создать новый проект на основе существующего»: при создании нового проекта `audiobook` пользователь может опционально выбрать существующий `.audiopie`-файл в качестве шаблона; новый проект будет предзаполнен метаданными этого проекта (автор, чтец, жанр, издатель, серия, обложка), но начнётся с пустых треков/глав и без запомненного пути файла (поэтому его нужно будет сохранить отдельно).
- Replace the split "Books" / "Metadata" tabs of a `series` project with a single, unified series management page: a two-column layout, left column the series metadata form (title, author, narrator, cover, description — same fields as before), right column the ordered, drag-and-droppable list of member audiobooks. There is no separate navigation rail.
  - **RU:** Заменить раздельные вкладки «Книги» / «Метаданные» проекта `series` единой страницей управления серией: двухколоночная раскладка, левая колонка — форма метаданных серии (название, автор, чтец, обложка, описание — те же поля, что и раньше), правая колонка — упорядоченный, поддерживающий drag-and-drop список входящих аудиокниг. Отдельной панели навигации (рельса) нет.
- Each member row in that list shows an editable series-position number, sourced from and written back to that member's own `metadata.seriesIndex` field (not a series-file-level field) — so members can be numbered arbitrarily (e.g. `15`, `16` for a series that only contains a later portion of a longer real-world series) independently of their position in the drag-ordered list.
  - **RU:** Каждая строка участника в этом списке показывает редактируемый номер позиции в серии, который читается из и записывается обратно в собственное поле `metadata.seriesIndex` этой книги (а не в поле уровня файла серии) — так участников можно нумеровать произвольно (например, `15`, `16` для серии, включающей лишь более позднюю часть более длинной реальной серии), независимо от их позиции в списке, определяемой drag-and-drop.
- The series page's "add member" action is a floating action button pinned to the bottom of the page (replacing the build FAB, which does not apply to a `series` project) and shown only on this page. It opens a small menu with two options: "Attach existing audiobook" (the existing file-picker flow) and "Create new audiobook in this series".
  - **RU:** Действие «добавить участника» на странице серии — это плавающая кнопка, закреплённая внизу страницы (заменяет кнопку сборки, которая неприменима к проекту `series`), и отображается только на этой странице. Она открывает небольшое меню с двумя пунктами: «Прикрепить существующую аудиокнигу» (существующий сценарий с выбором файла) и «Создать новую аудиокнигу в этой серии».
- "Create new audiobook in this series" opens a normal, blank `audiobook` editing workspace pre-filled with the series' shared metadata (author, narrator, cover), keeping the series as its active session context; the new book's path is automatically appended to the series' member list the first time that book is saved (it is not added before it has a save path).
  - **RU:** «Создать новую аудиокнигу в этой серии» открывает обычное пустое рабочее пространство редактирования `audiobook`, предзаполненное общими метаданными серии (автор, чтец, обложка), с сохранением серии как активного контекста сессии; путь новой книги автоматически добавляется в список участников серии при первом сохранении этой книги (до появления у неё пути сохранения она в список не добавляется).
- Inside an `audiobook` opened from a series (either an existing member or a newly created one), `MetadataForm` gains a "Part of series" callout with a "Remove from series" action (removes the book's path from the series file only, not the book itself) and a "Back to series" action (returns to the series management page), alongside the existing editable title field.
  - **RU:** Внутри `audiobook`, открытой из серии (существующего участника или только что созданной книги), `MetadataForm` получает блок «Входит в серию» с действием «Убрать из серии» (удаляет путь книги только из файла серии, не саму книгу) и действием «К серии» (возвращает на страницу управления серией), рядом с существующим редактируемым полем названия.
- "Create new" on the Project Manager opens a sub-screen with two tiles ("Audiobook" / "Series") instead of creating an audiobook immediately; the "Audiobook" tile also offers the existing-template choice from #27 as a secondary option.
  - **RU:** «Создать новый» в менеджере проектов открывает подэкран с двумя плитками («Аудиокнига» / «Серия») вместо немедленного создания аудиокниги; плитка «Аудиокнига» также предлагает выбор шаблона из #27 как вторичную опцию.

## Capabilities

### New Capabilities
- `project-types`: Defines the `audiobook`/`series` project type distinction, the `series` project's data shape (ordered audiobook references + shared metadata), and the UI for managing a series' member audiobooks.
  - **RU:** Определяет разделение типов проектов `audiobook`/`series`, структуру данных проекта `series` (упорядоченные ссылки на аудиокниги + общие метаданные) и UI для управления входящими в серию аудиокнигами.

### Modified Capabilities
- `project-persistence`: Project file format gains a `type` field (defaulting to `audiobook` when absent); adds a "create from existing project" flow that seeds a new project's metadata from a chosen template file.
  - **RU:** Формат файла проекта получает поле `type` (по умолчанию `audiobook`, если отсутствует); добавляется сценарий «создать на основе существующего проекта», заполняющий метаданные нового проекта из выбранного файла-шаблона.

## Impact

- `electron/main/types.ts` / `src/types.ts`: add `ProjectType = 'audiobook' | 'series'` and a `SeriesProject` type (title, author, narrator, coverPath, description, `audiobookPaths: string[]`); `SeriesMemberInfo` gains `seriesIndex?: number` (read from the member's own metadata).
- `electron/main/project.ts`: handle reading/writing both project types; default missing `type` to `'audiobook'` on open; new handler to patch a single member file's `metadata.seriesIndex` in place.
- `src/components/ProjectManager.tsx`: replace immediate "Create new" with a sub-screen/dialog offering "Audiobook" / "Series" tiles (and the existing-template picker as a secondary option under "Audiobook").
- Replace the two-tab `Books`/`Metadata` split with a single series management page (repurposing `src/components/SeriesEditor.tsx`, no longer a standalone `WorkspaceSidebar` section split): two columns — series metadata form (left) and drag-and-droppable, numbered member list (right), each row's number editable and bound to that member's own `metadata.seriesIndex`. `src/components/SeriesRail.tsx` is removed entirely (no persistent navigation column).
- New `AppContext` state `activeSeriesContext` (seriesPath + audiobookPaths, session-only) still tracks "this audiobook belongs to series X" for the "Part of series" callout and the auto-append-on-first-save behavior, but no longer drives a rendered rail.
- `App.tsx`: FAB stack shows an "Add book" button (opening the attach-existing/create-new menu) instead of the build FAB when a `series` project's page is active; `handleSaveProject` appends the current path to `activeSeriesContext.audiobookPaths` (persisting the series file) the first time a book created "in this series" is saved.
- `src/components/MetadataForm.tsx`: add a "Part of series" callout with "Remove from series" and "Back to series" actions, shown only when `activeSeriesContext` is set.
- `electron/preload/preload.ts`: new/extended `project.*` IPC methods (e.g. `project.newFromTemplate(templatePath)`, `project.openSeriesMember(path)`, `project.removeSeriesMember(seriesPath, memberPath)`, `project.reorderSeriesMembers(seriesPath, order)`, `project.updateMemberSeriesIndex(memberPath, seriesIndex)`).
- Updated styles: `src/styles/components/series-editor.scss` (two-column page layout); `src/styles/components/series-rail.scss` removed.
- `src/i18n/locales/en.json` / `ru.json`: new strings for the create-new sub-screen, the unified series page, the add-book menu, manual series index input, and "back to series" / "remove from series".
